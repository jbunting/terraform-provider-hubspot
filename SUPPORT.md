# Support

This is a community-maintained, open-source Terraform/OpenTofu provider. It is
not an official HubSpot product and carries no commercial support or SLA.

## Where to go

| I want to… | Go to |
|---|---|
| Read resource/data-source reference docs | [Terraform Registry](https://registry.terraform.io/providers/revosai/hubspot/latest/docs) (also on the [OpenTofu Registry](https://search.opentofu.org/provider/revosai/hubspot/latest)) |
| Ask a "how do I…" question | [GitHub Discussions](https://github.com/revosai/terraform-provider-hubspot/discussions) |
| Report a reproducible bug | [Open a bug report](https://github.com/revosai/terraform-provider-hubspot/issues/new?template=bug_report.yml) |
| Request a resource or feature | [Open a feature request](https://github.com/revosai/terraform-provider-hubspot/issues/new?template=feature_request.yml) |
| Report a security vulnerability | See [SECURITY.md](./SECURITY.md) — **not** a public issue |
| Understand what's planned | [ROADMAP.md](./ROADMAP.md) |

## Before opening an issue

- Confirm you're on the latest provider release.
- Search existing [issues](https://github.com/revosai/terraform-provider-hubspot/issues)
  and [discussions](https://github.com/revosai/terraform-provider-hubspot/discussions).
- Many failures are HubSpot **scope** or **product-tier** limitations rather
  than provider bugs — the error message usually says which scope or tier is
  required. See the [authentication guide](./docs/guides/authentication.md).

Issues are handled on a best-effort basis by volunteers. Well-scoped reports
with a minimal reproduction get resolved fastest.
